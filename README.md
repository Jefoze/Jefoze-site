# Jefoze

Портфолио с общей базой SQLite и серверной админкой. Нужен **Node.js 24+**.

## Запуск

1. `npm ci`
2. Скопируйте `.env.example` в `.env`, задайте собственный `ADMIN_PASSWORD` (минимум 12 символов).
3. `npm run build`
4. `npm start`

Сайт: `http://localhost:3001`, админка: `http://localhost:3001/#admin`.
Пароль из `.env` применяется только при создании базы. Затем пароль меняется в разделе безопасности админки и сохраняется на сервере как scrypt-хеш. Сессия действует 12 часов, смена пароля завершает другие сессии.

Для разработки запустите `npm run dev:server` и `npm run dev` в двух терминалах. Vite проксирует `/api` на порт 3001; при смене порта сервера измените `vite.config.js`.

## Публикация

Разместите проект на VPS или Node.js-хостинге с **постоянным диском**. Команда сборки: `npm ci && npm run build`, запуска: `npm start`. Укажите `DATA_DIR` на постоянном диске, `NODE_ENV=production` и `PUBLIC_ORIGIN=https://ваш-домен` (без завершающего слеша). Порт задаётся через `PORT`. HTTPS должен обслуживать хостинг или обратный прокси. Для `/api/events` отключите буферизацию прокси и установите таймаут больше 25 секунд.

Один процесс Node.js обслуживает и сайт, и API. GitHub Pages и другие чисто статические хостинги для такого запуска не подходят. Несколько экземпляров сервера с отдельными дисками не используют общую базу; эта конфигурация рассчитана на один экземпляр.

## Данные

Работы, контакты, статистика и загруженные изображения хранятся в `DATA_DIR/jefoze.sqlite` (по умолчанию `data/jefoze.sqlite`). Они доступны всем посетителям. Изменять их может только администратор. После сохранения страницы обновляются через SSE; резервная проверка выполняется каждые 30 секунд. Конфликт редактирования в двух админках отклоняется вместо перезаписи чужих изменений: обновите форму и повторите правки.

Контент, язык и тема не записываются в localStorage/sessionStorage. Язык и тема действуют до перезагрузки страницы. Для входа используется только защищённая HttpOnly cookie с идентификатором серверной сессии.

Начальная база содержит работы и контакты из исходного кода сайта. Ранее добавленные только в браузере данные автоматически не переносятся: перенесите их через админку до очистки старых данных браузера.

Для резервной копии остановите сервер и скопируйте каталог `DATA_DIR` целиком. Не удаляйте его при обновлении сайта. `.env` и база исключены из Git. Если пароль потерян, на остановленном сервере удалите записи таблиц `auth` и `sessions` средствами SQLite и задайте новый `ADMIN_PASSWORD` перед запуском; таблицу `content` оставьте нетронутой.

Проверки: `npm test` и `npm run build`.
